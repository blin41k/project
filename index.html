Сортировка пузырьком

Последовательно сравнивает соседние элементы и меняет их местами, если они стоят неправильно.

O(n2)

сравнение соседних элементов

для самого первого знакомства с алгоритмами сортировки

Текущий элемент сравнивается со следующим; если порядок неправильный, элементы меняются местами.

лучший: O(n2), средний: O(n2), худший: O(n2)

Сортировка пузырьком - простейший и один из самых известных алгоритмов сортировки. Идея заключается в последовательном сравнении соседних элементов. Если текущий элемент больше следующего, они меняются местами. Алгоритм повторяет проходы по массиву до тех пор, пока элементы не окажутся в правильном порядке. На его примере удобно понять саму идею обменной сортировки: массив меняется прямо на месте, без создания нового массива.

n = длина(массив)
для i от 0 до n - 2:
    для j от 0 до n - 2:
        если массив[j] > массив[j + 1]:
            поменять местами

Гномья сортировка

Перемещается по массиву вперед и назад: если соседние элементы стоят неправильно, меняет их местами.

O(n2)

шаг вперед и шаг назад

для наглядной демонстрации обменов соседних элементов

Если порядок правильный, алгоритм идет вперед; если нет - меняет элементы и возвращается назад.

лучший: O(n), средний: O(n2), худший: O(n2)

Гномья сортировка основана на идее движения по массиву как по линии цветочных горшков. Алгоритм смотрит на текущий и предыдущий элементы. Если они стоят в правильном порядке, он делает шаг вперед. Если порядок нарушен, элементы меняются местами, а алгоритм делает шаг назад. Так элемент постепенно возвращается туда, где он должен находиться. Если предыдущего элемента нет, алгоритм идет вперед; если следующего элемента нет, сортировка закончена.

i = 1
пока i < длина(массив):
    если i > 0 и массив[i - 1] > массив[i]:
        поменять местами
        i = i - 1
    иначе:
        i = i + 1

Сортировка вставками

Постепенно строит отсортированную часть массива и вставляет новый элемент в нужное место.

O(n2)

сдвиг и вставка

для маленьких или почти отсортированных массивов

Берется текущий элемент, а большие элементы слева сдвигаются вправо.

лучший: O(n), средний: O(n2), худший: O(n2)

Сортировка вставками работает по принципу пошагового построения отсортированной части массива. Алгоритм начинает со второго элемента, сравнивает его с предыдущими и сдвигает большие элементы вправо. Когда подходящее место найдено, текущий элемент вставляется туда. После каждого прохода отсортированная часть слева становится на один элемент больше. Этот алгоритм прост и хорошо работает на маленьких или почти отсортированных массивах, но на больших данных становится медленным.

для i от 1 до длина(массив) - 1:
    текущий = массив[i]
    пока слева есть элементы больше текущего:
        сдвинуть элемент вправо
    поставить текущий на место

Сортировка расческой

Улучшает сортировку пузырьком: сравнивает элементы не только рядом, но и на расстоянии.

O(n2)

сравнения с уменьшающимся шагом

для показа улучшения пузырьковой сортировки

Сначала шаг большой, потом он уменьшается, пока алгоритм не доходит до соседних элементов.

лучший: O(n log n), средний: около O(n2), худший: O(n2)

Сортировка расческой - это модификация сортировки пузырьком. Главное отличие в том, что сравниваются не только соседние элементы, а элементы на некотором расстоянии. Сначала шаг большой, затем он уменьшается примерно в 1.3 раза. За счет этого крупные элементы быстрее перемещаются ближе к своему месту, чем в обычной пузырьковой сортировке. Когда шаг становится равен 1, алгоритм фактически заканчивает работу обычными соседними сравнениями.

шаг = длина(массив)
пока шаг > 1 или были обмены:
    шаг = шаг / 1.3
    сравнивать элементы через этот шаг
    если порядок неправильный:
        поменять местами

Сортировка Шелла

Улучшает сортировку вставками за счет сравнения элементов с разными шагами.

зависит от шага

вставки с уменьшающимся шагом

для показа ускорения сортировки вставками

Сначала сравниваются дальние элементы, потом шаг уменьшается до одного.

лучший: O(n log n), средний: зависит от шага, худший: O(n2)

Сортировка Шелла - это улучшение сортировки вставками. Обычная сортировка вставками работает с соседними элементами, а сортировка Шелла сначала берет большой шаг между элементами. На каждом шаге элементы с таким интервалом частично упорядочиваются. Затем шаг уменьшается в два раза. Когда шаг становится равен 1, алгоритм превращается в обычную сортировку вставками, но массив уже частично подготовлен, поэтому сортировка идет быстрее.

шаг = длина(массив) // 2
пока шаг > 0:
    выполнить сортировку вставками с этим шагом
    шаг = шаг // 2

Поразрядная сортировка

Обрабатывает числа по разрядам: сначала единицы, потом десятки, сотни и так далее.

O(d * n)

сортировка по цифрам числа

для массивов с целыми неотрицательными числами

На каждом разряде числа раскладываются по корзинам от 0 до 9, затем корзины собираются обратно.

лучший: O(d * n), средний: O(d * n), худший: O(d * n)

Поразрядная сортировка работает путем обработки элементов по разрядам: единицы, десятки, сотни и так далее. На каждом разряде используется дополнительная сортировка по текущей цифре, чаще всего через подсчет или корзины. Для цифр создаются 10 корзин, числа раскладываются по ним, а затем корзины объединяются обратно. После обработки одного разряда алгоритм переходит к следующему, умножая разряд на 10. После обработки всех разрядов массив становится отсортированным.

разряд = 1
пока есть цифры в максимальном числе:
    разложить числа по корзинам 0-9
    собрать корзины обратно в массив
    разряд = разряд * 10

Сортировка слиянием

Делит массив на две части, сортирует их отдельно и затем сливает обратно.

O(n log n)

разделение и слияние

для демонстрации метода «разделяй и властвуй»

Массив делится до маленьких частей, а потом эти части собираются в правильном порядке.

лучший: O(n log n), средний: O(n log n), худший: O(n log n)

Сортировка слиянием использует метод «разделяй и властвуй». Алгоритм делит массив на две половины, затем отдельно сортирует левую и правую части. Деление продолжается до тех пор, пока подмассивы не станут совсем маленькими. После этого начинается слияние: из двух отсортированных половин выбирается меньший элемент и записывается обратно в исходный массив. Такой алгоритм эффективен по времени, но ему нужны дополнительные массивы для левой и правой частей.

если длина массива больше 1:
    разделить массив на левую и правую части
    отсортировать левую часть
    отсортировать правую часть
    слить две части обратно

Быстрая сортировка

Выбирает опорный элемент, делит массив на части и сортирует эти части отдельно.

O(n log n)

опорный элемент и разделение массива

для быстрой сортировки массивов на практике

Сначала выполняет перестановки на большом расстоянии, а потом сортирует левую и правую части.

лучший: O(n log n), средний: O(n log n), худший: O(n2)

Быстрая сортировка также использует метод «разделяй и властвуй». Алгоритм выбирает опорный элемент, затем переставляет массив так, чтобы элементы меньше опорного оказались слева, а элементы больше - справа. После разделения левая и правая части сортируются рекурсивно. В отличие от сортировки пузырьком, обмены могут происходить на большом расстоянии друг от друга. В нашем коде опорным элементом берется последний элемент, как в псевдокоде из материала.

выбрать опорный элемент
переставить меньшие элементы влево
переставить большие элементы вправо
отсортировать левую часть
отсортировать правую часть

Stooge Sort - придурковатая сортировка

Сравнивает элементы на концах отрезка, а затем три раза рекурсивно сортирует части массива.

O(n2.7095)

рекурсивная сортировка первых 2/3, последних 2/3 и снова первых 2/3

для демонстрации работающего, но крайне неэффективного рекурсивного алгоритма

Алгоритм работает честно, но делает много повторной работы на одних и тех же участках массива.

O(n^(log 3 / log 1.5)), примерно O(n2.7095)

Придурковатая сортировка сравнивает края отрезка, а потом три раза сортирует его части: первые 2/3, последние 2/3 и снова первые 2/3.

    закончить
треть = длина отрезка // 3

Сортировка перестановками перебирает варианты расположения элементов, пока не найдет отсортированный. Для больших массивов на сайте используется безопасное завершение.

Сортировки на примере фруктов

В повседневной жизни и в программировании мы часто упорядочиваем данные: список покупок, книги на полке или результаты поиска. Алгоритмы сортировки помогают расположить элементы в нужном порядке.

В этом примере вместо чисел используются фрукты разного размера. Чем меньше фрукт, тем раньше он должен стоять в отсортированном списке.

🍎 яблоко мелкий фрукт
🍐 груша средний фрукт
🍉 дыня большой фрукт
🧺 корзина очень большой объект

В программе фрукт можно представить как пару: (размер, идентификатор). Например, (🍎, 1) - первое яблоко, а (🍐, 2) - вторая груша.

Пример кода

Функция сравнивает два фрукта по размеру. Идентификатор нужен, чтобы одинаковые фрукты можно было отличать друг от друга. 

from typing import List, Tuple

def compare_fruits(fruit1: Tuple[str, int], fruit2: Tuple[str, int]) -> int:
    order = {"🍎": 0, "🍐": 1, "🍉": 2, "🧺": 3}
    size1 = order.get(fruit1[0])
    size2 = order.get(fruit2[0])

    if size1 < size2:
        return -1
    if size1 > size2:
        return 1
    return 0

Обычные сортировки

Bubble Sort

Алгоритм сравнивает соседние фрукты. Если левый фрукт больше правого, они меняются местами. Так крупные фрукты постепенно уходят вправо, а маленькие оказываются ближе к началу списка.

Insertion Sort

Алгоритм берет фрукты по одному и вставляет каждый на правильное место в уже отсортированной части списка. Это похоже на то, как человек раскладывает карты в руке по порядку.

Selection Sort

Алгоритм ищет самый маленький фрукт в неотсортированной части и ставит его на первое свободное место. Потом повторяет то же самое для оставшихся фруктов.

Шуточные сортировки

BogoSort

Корзину с фруктами просто случайно перемешивают, а потом проверяют, не получился ли правильный порядок. Если нет - перемешивают снова. Это смешной, но почти бесполезный способ.

BozoSort

Клоун случайно выбирает два фрукта и меняет их местами. Потом проверяет, стал ли список отсортированным. Если нет - снова меняет случайную пару.

Stooge Sort

Алгоритм смотрит на края ряда фруктов, меняет их при необходимости, а потом несколько раз странно сортирует большие части ряда: первые 2/3, последние 2/3 и снова первые 2/3.

PermSort

Алгоритм перебирает разные варианты расположения фруктов, пока не найдет правильный порядок. Идея простая, но вариантов становится слишком много.

Babushkin Sort

Шуточная идея: будто у нас заранее есть “волшебная записка”, в какие позиции нужно положить каждый фрукт. Если такая записка уже есть, все просто. Проблема в том, что ее нужно откуда-то заранее получить, поэтому это не рабочий алгоритм на сайте.
