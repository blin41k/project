# Демонстратор алгоритмов сортировки массивов

Учебный проект по дисциплине «Алгоритмизация и программирование».
Тема проекта: программа-демонстратор алгоритмов сортировки массивов.

## Цель проекта

Цель работы - показать работу разных алгоритмов сортировки на одномерном массиве.
Пользователь может создать массив, выбрать алгоритм и посмотреть, как элементы меняются местами во время сортировки.
Также на странице есть сравнение алгоритмов по времени, количеству сравнений, перестановок и шагов анимации.

## Что реализовано

В проекте реализованы следующие возможности:

- генерация случайного массива;
- ввод своего массива вручную;
- выбор размера массива от 5 до 100 элементов;
- выбор скорости анимации;
- пошаговая визуализация сортировки;
- вывод исходного и отсортированного массива;
- статистика по выбранному алгоритму;
- сравнение всех алгоритмов на одном и том же массиве;
- краткое описание и псевдокод для каждого алгоритма.

## Алгоритмы в проекте

На сайте представлены 8 алгоритмов сортировки:

- сортировка пузырьком;
- гномья сортировка;
- сортировка вставками;
- сортировка расческой;
- сортировка Шелла;
- поразрядная сортировка;
- сортировка слиянием;
- быстрая сортировка.

## Используемые технологии

- Python - реализация алгоритмов сортировки и подсчет статистики.
- HTML - структура страницы.
- CSS - внешний вид страницы и адаптация под разные размеры экрана.
- JavaScript - управление интерфейсом, запуск Python-кода, анимация массива.
- Pyodide 0.29.3 - запуск Python прямо в браузере.

## Как устроена работа

Основная логика сортировок находится в файле `sorting.py`.
Каждая функция сортировки возвращает отсортированный массив, статистику и список шагов для анимации.
Основные тексты страницы и описания алгоритмов находятся в файле `index.html`.

Основа Python-кода сделана по псевдокоду из материалов практики и лабораторной работы: пузырек, гномья, поразрядная и быстрая сортировка повторяют идеи из практики по сортировкам.
Дополнительно к алгоритмам добавлены только шаги для анимации, подсчет статистики и JSON-функции, чтобы Pyodide мог запускать Python прямо на сайте.

JavaScript загружает Pyodide, затем загружает файл `sorting.py` и вызывает нужные Python-функции.
После этого JavaScript показывает столбцы массива на странице и постепенно применяет шаги сортировки.

Для сравнения алгоритмов используется один и тот же исходный массив.
Так удобнее оценивать результаты, потому что все алгоритмы работают с одинаковыми данными.

## Структура файлов

- `index.html` - основная HTML-страница.
- `css/style.css` - стили сайта.
- `css/media.css` - стили для телефонов, планшетов и разных размеров экрана.
- `js/app.js` - работа кнопок, анимации и связь страницы с Python.
- `pictures/favicon.ico` - иконка сайта во вкладке браузера.
- `sorting.py` - алгоритмы сортировки, генерация массива и подсчет статистики.
- `README.md` - описание проекта.

## Как проверить работу

1. Открыть страницу проекта в браузере.
2. Дождаться загрузки Python через Pyodide.
3. Нажать «Сгенерировать» или ввести свой массив.
4. Выбрать алгоритм сортировки.
5. Нажать «Сортировать» для демонстрации выбранного алгоритма.
6. Нажать «Сравнить все», чтобы получить таблицу сравнения всех алгоритмов.

Важно: для загрузки Pyodide нужен интернет, так как библиотека загружается из CDN.
